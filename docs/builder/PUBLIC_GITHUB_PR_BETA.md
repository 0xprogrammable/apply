# Public GitHub application intake

The complete project stays in the applicant-owned public GitHub repository. A draft pull request to
`0xprogrammable/submit-launch:main` carries exactly six generated files under one
`submissions/<application-id>/` directory.

The intake is `open` for the exact stable Hookbuilder version named by the current Submit a Launch release. Existing
pull requests already opened against `0xprogrammable/programmable` or `0xprogrammable/hookbuilder` remain on those
legacy review threads and are not silently moved or relabeled.

The application PR is a public review thread, not source custody, acceptance, an audit, deployment authorization,
provider support, availability, or Uniswap endorsement. Maintainer-authored registry promotion is a separate action
bound to the exact reviewed repository id, commit, tree, evidence, and acceptance record.
